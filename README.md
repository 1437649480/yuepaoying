## 一、这是什么

一个**不需要 ROOT** 的安卓虚拟定位工具：改位置、摇杆移动、搜索地点、输入坐标，  
外加本项目新增的**地图画路线 → 按走路/跑步/骑行速度自动走完 → 可循环**的功能。

- 包名：yiyisiwu.yi.si
- 支持系统：Android 8.0（API 27）及以上
- 架构：arm64-v8a

## 四、安装

从本仓库的 [Releases](https://github.com/1437649480/yuepaoying/releases) 下载 `app-release.apk` 直接安装即可，无需 ROOT。

### 调试日志版 APK（定位排障专用）

`release/影梭_debug_日志版.apk` 是**单独打包的排障版本**，只在需要排查
「定位不可用，请检查 GPS 是否开启」这类问题时使用，日常使用请装上面的 `app-release.apk`。

| 项 | 值 |
| -- | -- |
| 包名 | `yiyisiwu.yi.si` |
| 版本 | 1.12.3（versionCode 1123） |
| 大小 | 约 23 MB |
| SHA-256 | `144691268c385186dbfa7bf09b2e40414c05b1e69d7fe427f5705d4c0cc1dc7a` |

**它与正式版的差异**（都是打包时的字节码注入，不涉及本仓库源码）：

1. 百度定位请求中的上传包名伪装为 `com.zcshou.gogogo`
2. 用内置的原版证书副本计算 `mcode`（`证书SHA1;包名`），绕过 AK 校验失败
3. 全流程日志**写入文件**，从进程启动第一刻开始记录
4. 欢迎页右上角新增 **「调试日志」** 菜单：导出到剪贴板 / 清空日志文件
5. 未捕获异常（闪退）的完整堆栈一并写入日志文件

**使用方法**

1. 安装后打开 App，先不要点「进入应用」
2. 点右上角 **调试日志** → **导出日志（复制到剪贴板）**
   内容含机型、系统版本、权限状态、当前 AK、真实签名、伪造 mcode 和日志尾部
3. 直接粘贴发出来即可；日志文件同时留在设备上：

```
/sdcard/Android/data/yiyisiwu.yi.si/files/yingsuo_main.log     # 主进程
/sdcard/Android/data/yiyisiwu.yi.si/files/yingsuo_remote.log   # 定位服务进程
```

单个文件超过 2 MB 会在下次启动时自动清空，不需要手动维护；
菜单里的「清空日志文件」可随时手动清掉，方便复现前取干净的现场。

连接的电脑上也可以直接取完整日志：

```bash
adb -s <设备> pull /sdcard/Android/data/yiyisiwu.yi.si/files/yingsuo_main.log
```

**看日志时先认这几个码**

| locType / errorcode | 含义 | 说明 |
| -- | -- | -- |
| 61 | GPS 定位成功 | 正常 |
| 161 | 网络定位成功 | 正常 |
| 62 / 63 | 定位失败，正在重试 | 通常换个环境或等网络 |
| 505 | AK 鉴权失败 | 上传包名与 AK 绑定信息不一致，可用本调试版验证 |
| 201 | AK 被开发者在控制台禁用 | **服务端状态，客户端无法修复**，需到百度地图开放平台重新启用 / 申请 AK |

> 注意：
> - 这个版本是**重签名**的，不能覆盖安装到已装正式版的机器上，需要先卸载（会丢设置）。
> - 它**不代表源码分支**——仓库里的源码不含上述日志与伪装逻辑，日志能力仅存在于这个 APK 中。


## 五、构建

```bash
# 环境：JDK 21、Android SDK（platform 32 + build-tools 36）
# 1. 配置 SDK 路径
echo "sdk.dir=D:/vm/android-sdk" >> local.properties

# 2. 配置百度地图 KEY（见上节）
#    在 local.properties 中写 MAPS_API_KEY=你的AK

# 3. 构建
./gradlew assembleRelease     # 产物：app/build/outputs/apk/release/
./gradlew assembleDebug
```

签名密钥位于 `keystore/`（沿用上游公开仓库中的 keystore，仅供本项目自编译使用）。  
**若你要自行重新编译并长期维护，建议自行生成一套 keystore 并替换。**
