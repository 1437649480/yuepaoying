## 一、这是什么

一个**不需要 ROOT** 的安卓虚拟定位工具：改位置、摇杆移动、搜索地点、输入坐标，  
外加本项目新增的**地图画路线 → 按走路/跑步/骑行速度自动走完 → 可循环**的功能。

- 包名：yiyisiwu.yi.si
- 支持系统：Android 8.0（API 27）及以上
- 架构：arm64-v8a

## 四、安装

从本仓库的 [Releases](https://github.com/1437649480/yuepaoying/releases) 下载 `app-release.apk` 直接安装即可，无需 ROOT。


## 五、构建

```bash
# 环境：JDK 21、Android SDK（platform 32 + build-tools 36）
# 1. 配置 SDK 路径
echo "sdk.dir=D:/vm/android-sdk" >> local.properties

# 2. 配置百度地图 KEY（见上节）
#    在 local.properties 中写 MAPS_API_KEY=你的AK

# 3. 构建
./gradlew assembleRelease     # 产物：app/build/outputs/apk/release/
./gradlew assembleDebug
```

签名密钥位于 `keystore/`（沿用上游公开仓库中的 keystore，仅供本项目自编译使用）。  
**若你要自行重新编译并长期维护，建议自行生成一套 keystore 并替换。**
